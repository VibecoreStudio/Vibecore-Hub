# Vibecore Hub ユーザーガイド

[プロジェクトページ](../README_JA.md) · [中文](USER_GUIDE.md) · [English](USER_GUIDE_EN.md)

> v1.2.1 のアプリ画面は現在、簡体字中国語のみです。日本語 UI は今後のバージョンで対応予定です。

> [!IMPORTANT]
> ## ほぼすべての機能と項目で右クリックが使えます
> **上部のモジュールアイコンを右クリックすると設定が開きます。ショートカット、メモ、フォルダー、音声プリセットを右クリックすると、編集、削除、その他の操作を表示できます。右クリックを覚えれば、アプリの基本操作はほぼ完了です。**

## 初回起動

ポータブル版を展開し、`Vibecore Hub.exe` を実行します。インストールは不要です。設定と内容は、実行ファイルと同じ場所に自動作成される `data` フォルダーへ保存されます。別の PC へ移す場合は、アプリのフォルダーごとコピーできます。

次のバージョンでは、簡体字中国語、English、日本語を切り替えるアプリ内言語メニューを追加します。

## 基本操作

| 場所 | 左クリック | 右クリック / ドラッグ |
| --- | --- | --- |
| Vibecore ロゴ部分 | ドラッグしてウィンドウを移動 | 右クリックで全体設定 |
| 上部のモジュールアイコン | モジュールを開閉 | 右クリックでモジュール設定 |
| ショートカット、メモ、フォルダー、音声プリセット | 開く・実行する | 右クリックで編集、削除、アイコン変更 |
| モジュール下部の `···` | — | 上下ドラッグで高さを変更 |
| ウィンドウ左右の枠 | — | 左右ドラッグで幅を変更 |
| ピン | 最前面表示を切り替え | — |
| `×` | システムトレイへ格納 | — |

## ショートカットライブラリ

- `+` からアプリ、ファイル、フォルダー、定型文、ショートカットグループを追加できます
- `.exe`、ファイル、フォルダー、Windows ショートカットをモジュールへ直接ドロップすることもできます
- 左クリックで実行し、ショートカットグループはメインウィンドウの横に開きます
- 右クリックで編集、削除、カスタムアイコン設定、既定アイコンへの復元ができます
- ドラッグで並べ替えたり、開いているグループへ項目を移動したりできます
- 上部のショートカットアイコンを右クリックすると、アイコンサイズ、列数、間隔を変更できます

## メモ

- `+` からタイトルと本文を持つメモを作成します
- 左クリックで表示し、右クリックで編集または削除します
- カードはドラッグで並べ替えられます
- 上部のメモアイコンを右クリックすると、カードの高さ、1/2/3 列表示、表示ウィンドウの動作を設定できます

## 全体検索

キーワードを入力すると、ショートカット、フォルダー、メモをまとめて検索できます。結果をクリックすると開く、または実行します。

## フォルダーディレクトリ

- `+` からよく使うフォルダーを追加し、左クリックで開きます
- 右クリックで編集または削除し、ドラッグで並べ替えます
- 上部のフォルダーアイコンを右クリックすると、列数とボタンの高さを設定できます

## オーディオ切り替え

- 上部のスライダーで、現在の既定再生デバイスのメイン音量を調整します
- `+` から入力デバイスと出力デバイスを選び、プリセットを作成します
- プリセットをクリックすると、既定の再生デバイスと通信デバイスをまとめて切り替えます
- 使用中のプリセットには「現在」を示す表示が付きます
- 右クリックで編集または削除し、機器を変更した場合は編集画面からデバイス一覧を更新できます

## 全体設定

Vibecore ロゴ部分を右クリックすると、PC プロファイルとテーマの切り替え、上部モジュールの並べ替え、データのバックアップと復元ができます。PC ごとに異なるプロファイルを使用できます。

## 終了

`×` はシステムトレイへ格納するだけです。完全に終了するには、トレイアイコンのメニューから「終了」を選択してください。
