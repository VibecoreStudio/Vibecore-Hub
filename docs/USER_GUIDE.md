# Vibecore Hub 使用指南

[返回项目首页](../README.md) · [English](USER_GUIDE_EN.md) · [日本語](USER_GUIDE_JA.md)

> [!IMPORTANT]
> ## 几乎所有功能和内容都支持右键
> **顶部功能图标右键进入该功能设置；快捷图标、便笺、目录和音频预设右键进行编辑、删除或查看更多操作。记住右键，基本就掌握了整个软件。**

## 首次使用

解压绿色版后运行 `Vibecore Hub.exe`，无需安装。程序会在自身目录创建 `data` 文件夹，用来保存所有设置和内容。换电脑时可以复制整个程序文件夹。

当前 v1.2.1 软件界面为简体中文；下一版本将加入简体中文、English、日本語的软件内切换菜单。

## 必须知道的操作

| 位置 | 左键 | 右键 / 拖动 |
| --- | --- | --- |
| 左上角 Vibecore 图标区域 | 拖动窗口 | 右键打开全局设置 |
| 顶部功能图标 | 打开或关闭模块 | 右键打开该模块设置 |
| 快捷图标、便笺、目录、音频预设 | 打开或执行 | 右键编辑、删除或设置图标 |
| 模块底部 `···` | — | 上下拖动调整该模块高度 |
| 窗口左右边缘 | — | 左右拖动调整整体宽度 |
| 右上角图钉 | 切换始终置顶 | — |
| 右上角 `×` | 隐藏到系统托盘 | — |

## 快捷方式库

- 点击 `+` 手动添加程序、单个文件、文件夹、常用文本或收纳文件夹
- 也可以把 `.exe`、文件、文件夹和 Windows 快捷方式直接拖入模块自动添加
- 左键快捷项执行；左键收纳文件夹在主窗口左侧打开分组窗口
- 右键快捷项可编辑、删除、设置自定义图标或还原默认图标
- 拖动图标可调整顺序；也可以将快捷项拖进已打开的收纳文件夹
- 右键顶部“快捷方式库”图标，可设置图标大小、每行数量和间距

## 便笺卡片

- 点击 `+` 新建便笺，填写标题和内容
- 左键便笺打开阅读窗口；右键可编辑或删除
- 拖动便笺卡片调整顺序
- 右键顶部“便笺”图标，可设置卡片高度、每行 1/2/3 个，以及阅读窗口的打开方式

## 全局搜索

输入关键词可同时搜索快捷方式、常用目录和便笺，点击结果即可打开或执行。

## 文件夹目录

- 点击 `+` 添加常用文件夹，左键直接打开
- 右键目录卡片可编辑或删除，拖动卡片可调整顺序
- 右键顶部“文件夹目录”图标，可设置每行按钮数和按钮高度

## 音频切换

- 顶部滑杆控制当前默认播放设备的主音量
- 点击 `+` 添加预设，并选择输入设备和输出设备
- 点击预设即可一键切换；程序会同时设置默认播放设备和默认通信设备
- 带“当前”标识的卡片表示正在使用的预设
- 右键预设可编辑或删除；设备变化后可在编辑窗口刷新设备

## 全局设置

右键左上角 Vibecore 图标区域，可切换电脑配置与主题、调整顶部功能顺序，以及备份或恢复数据。不同电脑可以使用独立配置。

## 退出程序

点击 `×` 只会隐藏到系统托盘。需要完全退出时，请使用托盘图标菜单中的“退出”。
