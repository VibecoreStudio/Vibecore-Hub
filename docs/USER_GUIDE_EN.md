# Vibecore Hub User Guide

[Project home](../README_EN.md) · [中文](USER_GUIDE.md) · [日本語](USER_GUIDE_JA.md)

> The v1.2.1 application interface is currently available in Simplified Chinese. English localization is planned for a future release.

> [!IMPORTANT]
> ## Almost every feature and item supports right-click
> **Right-click a top module icon for its settings. Right-click a shortcut, note, folder, or audio preset to edit, delete, or find more actions. Remember to right-click and you already know most of the application.**

## First launch

Extract the portable archive and run `Vibecore Hub.exe`; no installation is required. The application creates a local `data` folder beside the executable for settings and content. Copy the entire application folder when moving to another computer.

The next release will add an in-app language menu for Simplified Chinese, English, and Japanese.

## Essential controls

| Location | Left-click | Right-click / drag |
| --- | --- | --- |
| Vibecore logo area | Drag to move the window | Right-click for global settings |
| Top module icon | Open or close the module | Right-click for module settings |
| Shortcut, note, folder, or audio preset | Open or run | Right-click to edit, delete, or change its icon |
| `···` below a module | — | Drag vertically to resize the module |
| Window side borders | — | Drag horizontally to resize the window |
| Pin button | Toggle always-on-top | — |
| `×` button | Hide to the system tray | — |

## Shortcut Library

- Select `+` to add an app, file, folder, text snippet, or shortcut group manually
- You can also drop an `.exe`, file, folder, or Windows shortcut into the module
- Left-click an item to run it; a shortcut group opens beside the main window
- Right-click an item to edit, delete, set a custom icon, or restore its default icon
- Drag items to reorder them or move one into an open shortcut group
- Right-click the top Shortcut Library icon to change icon size, columns, and spacing

## Notes

- Select `+` to create a note with a title and content
- Left-click a note to open its viewer; right-click to edit or delete it
- Drag cards to reorder them
- Right-click the top Notes icon to adjust card height, choose 1/2/3 columns, and select the viewer behavior

## Global Search

Enter a keyword to search shortcuts, folders, and notes together. Select a result to open or run it.

## Folder Directory

- Select `+` to add a frequently used folder; left-click it to open
- Right-click a folder card to edit or delete it; drag cards to reorder them
- Right-click the top Folder Directory icon to adjust columns and button height

## Audio Switcher

- The slider controls the master volume of the current default playback device
- Select `+` to create a preset and choose its input and output devices
- Select a preset to switch devices; the default playback and communication devices are set together
- The active preset is marked as current
- Right-click a preset to edit or delete it; refresh devices from the editor after hardware changes

## Global settings

Right-click the Vibecore logo area to switch computer profiles and themes, reorder top modules, or back up and restore your data. Each computer can use a separate profile.

## Exit

The `×` button only hides Vibecore Hub to the system tray. To quit completely, use Exit from the tray icon menu.
